# **Project HBO Max Cloning**  🖥️

### The project is a clone of the HBO Max website, aiming to reproduce the interface, with some modifications, applying the topics covered throughout the CSS classes on the Digital Innovation One platform. The website is in Portuguese and I will be updating the website to English.

### 📜 Technologies

- HTML — Page structure
- CSS — Styling and layout
- VS Code — Development environment

### 📁 Features

- Responsiveness
- Interactive website overall

### 📍The Process

This was one of the biggest project I’ve done, it was made from scratch. The HTML and CSS were done by looking at the original HBO website and trying to copy the layout using the developer tool inside the browser of choice. Overall it was a fun and could put into practice some of the learnings we saw in class.

### 🚦Running the Project

- Clone the repository
- Open the project in your preferred code editor.
- Run it with live server
